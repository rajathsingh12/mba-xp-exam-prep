# MBA XP Exam Prep

Plain English study notes for the MBA Big Data Analytics course.

Built from simplified lecture notes — one URL, all modules.

## Usage

Visit: https://rajathsingh12.github.io/mba-xp-exam-prep/

## Rebuild

```bash
npm install marked
node build.js
```

Add more modules by placing `*-plain-english.md` files in `module-N/` folders and re-running the build.
